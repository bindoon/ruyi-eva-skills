# 创意复刻

从 `get_content_context.referenceBreakdown` 读剧情、镜头、主体和禁项。缺拆解时按 [流程](workflows.md) 分析参考片，已有结果直接写。优先保留开场、关键动作关系、节奏、揭晓与情绪变化，按当前时长重排。动作放不下先砍次要动作和台词，保留必要交接。用户或参考明确要连续长镜时，按 [一镜到底](storyboard.md#一镜到底) 写。

把参考内容改写为当前人和货的独立脚本。人物使用已选角色 face，商品用当前商品真图，场景和道具优先复用素材。带货缺图可先存稿，确认前说明需要上传或从商品库选。补素材见 [主体图](subject-images.md)。保留适用于本片的禁项，原片人物、商品、品牌、编号和口播不带入正文。参考片用于拆解，实际动作要写清，不能用 `@视频n` 代替。

当前 goal 有配方时只借匹配的口头禅、固定结尾或音色，结构跟拆解。旧结构化稿可用 `sourceShotIndex` 和 `sourceSubjectName` 记录镜头与主体的对应关系。
