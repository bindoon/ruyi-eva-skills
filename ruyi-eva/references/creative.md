# 定方向

写表之前先把「这一集拍什么」定下来。原创要给用户选角度；复刻的角度来自拆解，不问用户（见 replication.md）。

## 1. 盘点近作

`get_content_context.recentEpisodes` 是同单元最近的片子（标题、caption、说明、钩子、提示词预览、变量）。已经拍过的情境、场景、钩子、变量取值不要再复述成下一集；`angle` 为空也要按正文去重。保存时系统也会按近作查重，撞车会进 `mustFix` / `warnings`。

## 2. 配方是契约（原创）

生效配方在 `get_content_context.playbook`（只认本条 `brief.goal` 的那一份，不借另一个 goal 的）：

| 配方字段 | 怎么落到分镜 |
| --- | --- |
| `structure` | 镜头结构。里面的 `【变量名】` 用 `card.variables` 的取值替换后再写逐镜 |
| `variables[]` | 每个变量都要在 `card.variables` 里给值；优先从 `pool` 里选，池外新值可以写但会被提示 |
| `fixedEnding` | 固定结尾，进最后一镜，每集一样 |
| `visualHammerShots` | 视觉锤，每镜画面都点出对应那一个 |
| `voice` + 人设 `soul.catchphrases` / `soul.toneRules` | 进口播；每条至少一句口头禅 |
| `sceneRotation` + `unit.world.scenes` | 轮换常驻场景（`kind=living` 为主，`passing` 点缀），换季换光线不换地点 |
| `durationSeconds` | 默认时长，各镜之和必须等于 brief 时长 |

画面语法来自 `unit.world.cameraGrammar`。配方没有变量时按无变量执行，收尾提醒用户补一版带变量的配方。

## 3. 给 2–3 个角度

每个角度一行，写清：**支柱 / 变量取值 / 钩子 / 借用哪条参考 / 与近作的差异**。编号列出，等用户选；用户说「直接写」就取第 1 个。

- **角度**（`card.creativeAngle`）是整条片的切入点，一句话能复述：「极致体型反差：小个子大领导」「10 秒挑战：棒状产品能不能淡纹」。
- **钩子**（`card.hookType`）是前 3 秒让人停下的手法，从下表十种里选一种。一个角度可以配不同钩子；给用户看的是角度。
- 方向来自配方与人设，不来自公开片排行。带货可以借对标片的钩子，写明借哪条。

### 爆款自检

每个角度至少命中 3 项，否则回炉，不要用「日常分享 / 好物推荐 / 生活记录」充数：

- **痛点真实**：对应这个账号或这个品的具体麻烦，不是「大家都很忙」。
- **钩子有张力**：前 3 秒能停住，不是平淡陈述。
- **有证明**：中段有观众不知道但有用的东西（对比、数字、反常识、现场演示）。
- **情绪有转折**：至少一次明显转向，不是「平淡 → 平淡」。

## 4. 前三秒钩子

钩子是前 1–3 秒，任务是让人停下，不是先把整条讲一遍。口播钩子一句短话、一口气能说完；前三秒必须已经和产品或产品要解决的问题有关。

| # | 技巧 | 台词句式 | 第 1 镜画面 |
| --- | --- | --- | --- |
| 1 | 猎奇揭秘 | "你肯定没见过 …… 还能这样。" | 那个反常的东西直接入画 |
| 2 | 放大痛点 | "你的 …… 是不是每次都 ……" | 痛点正在发生的特写，先不出产品 |
| 3 | 情感共鸣 | "我妈拿到 …… 第一句话是 ……" | 一张脸或一个动作，不是产品 |
| 4 | 直观效果 | "左边是 ……，右边是 ……，同一个 ……" | 对比锁在同一帧 |
| 5 | 人群圈定 | "干 …… 这行的，先别划走。" | 观众的工作环境或工具 |
| 6 | 背书承诺 | "…… 师傅让我 …… / 没效果全额退。" | 资质或承诺直接上屏 |
| 7 | 场景激发 | "凌晨三点又 ……，所以我 ……" | 日常场景先出，产品晚一点进 |
| 8 | 剧情引入 | "这东西我差点就扔了。" | 从动作中段切入，不铺垫 |
| 9 | 促销优惠 | "这个 …… 今天只要 ……" | 第一帧看清价格或品牌标 |
| 10 | 国货 / 本土 | "…… 产的 ……，比 …… 还好用。" | 产地标识先出，再出产品 |

选型：

- 产品差异能拍出来 → 4 或 1。
- 解决家务、反复出现的烦恼 → 2 或 7。
- 买家画像窄、职业清楚 → 5，同一句加一个具体数字。
- 信任是障碍（新品牌、高单价）→ 6 或 10。背书、退款只有 brief 里有才能写。
- 转化目标且 brief 有明确价格 → 9。brief 没给的折扣不要编。
- 人设是讲故事的口吻 → 3 或 8，但第 1 镜结束前产品必须出现或被点名。

台词：用具体数字（尺寸、时间、价格），只对一个人说，承诺带约束（「15 秒内」「不用脱靴子」），可以先说一个常见错误再反着来。第一帧字幕复述口播钩子。

不要：「大家好 / 今天给大家分享」、Logo 定格、包装慢推开场；一句钩子叠两种技巧；第 1 镜重新开头（`hookScript` 第一句就是钩子，第 1 镜接着走）。

## 5. 节奏

| 总时长 | 镜数 | 结构 | 每镜 |
| --- | --- | --- | --- |
| 15s | 3–4 | 一个问题、一个证明、一个收尾 | 3–5s |
| 20s | 5 | 钩子 / 痛点 / 功效 / 卖点 / CTA | 3–5s |
| 30s | 4–6 | 钩子、一次演示或对比、一次回顾、CTA | 4–6s |

一镜一个意思；某镜没有改变观众看到或相信的东西就删掉。但**压时长时不删镜**，缩时长、砍口播。

## 6. 按片型

### 养号（`goal=persona_ip`）

人设在常驻场景里过日子。不卖货、不挂车、不出价格、不用硬广结构（痛点 → 功效 → CTA）。

- 角度写成「在哪 + 发生什么 + 人设怎么反应」。近作换一套场景 / 道具 / 整活，不要只换一句口播。
- 15 秒结构：钩子 3s（人设 + 常驻场景一眼认出，口头禅或标志动作）→ 情境 4–5s（一件小事发生）→ 反应 4–5s（性格在这里体现，视觉锤）→ 固定结尾 3s。
- 每集不变：固定结尾、口头禅、视觉锤、画面语法、人设主体。每集可变：变量取值、支柱轮换、钩子手法、场景。
- 主体只用人设 face 与 `world.scenes` 场景图；配角出镜用配角 face。
- 口播第一人称对粉丝说，一镜一句，结尾不说再见，落在固定结尾上。可以无人声。

### 带货（`goal=product_sales`）

TikTok Shop 挂车，目标即时购买。**没有商品图不拍**（外观会漂）。

先写购买障碍，再写触发，再选一种叙事填五拍（不另加镜）：

| 障碍 | 触发 | 角度 | 叙事 |
| --- | --- | --- | --- |
| 怀疑便捷产品效果不如专业 | 眼见为实：现场前后对比 | 10 秒挑战 | 痛点解决 |
| 觉得贵 / 不急 | 损失厌恶：每天多花的钱 | 算账 | 痛点解决 |
| 不知道怎么用 | 低门槛：一抹就好 | GRWM 跟我一起 | 教程跟做 |
| 不信新品牌 | 背书：成分名 + 数字 | 成分课 | 口播背书 |
| 日常会用但怕硬广 | 场景代入：顺手拿起来 | 生活里顺手用 | 场景植入 |
| 效果要看见才信 | 第一人称实测 | 开箱 / 当场试 | 开箱测评 |

五拍（15–20 秒）：

| beat | 时长 | 情绪 | 画面 | 口播 |
| --- | --- | --- | --- | --- |
| 真实体验 / 钩子 | 3s | 怀疑与挑战 | 商品贴近脸，指着问题 | 反问：这玩意真的能…吗？ |
| 用户痛点 | 4s | 焦虑 | 展示问题特写 | 我的…看起来好深 |
| 产品功效 | 5s | 专注与惊喜 | 使用特写，质地变化 | 成分名 + 一抹就… |
| 卖点 / Proof | 4s | 震惊 | 同部位同光线前后对比 | 看我用前用后 |
| CTA | 4s | 推荐 | 举产品对镜头 | shop the bag |

- 商品第 1 镜就要出现或被点名（场景植入可到第 2 镜）。每个卖点落到一个可拍动作（摩擦、水淋、拆解、前后对比、录屏），不要只写进口播。
- 一条片只选一种叙事：效果能拍用痛点解决或开箱；生活场景用场景植入；不会用用教程跟做；不信品牌用口播背书。
- 景别有变化：中景直视 → 特写 → 微距对比 → 中景展示。场景固定、光线充足。
- `card.purchaseBarrier` / `card.coreTrigger` 必填。
- 不要：Logo 定格开场、「链接在下面」「赶紧下单吧」、把商品改成生活方式片、为了套叙事拆成 6–7 镜。

### 搞笑剧情（宠物、情侣、职场反差、拟人化）

多为养号；带货时商品只做道具。

- 一个**反差设定**撑全片（体型 / 地位 / 期待反差），角度写成「谁 vs 谁：一句话设定」。
- 5–6 镜，每镜 2.5–4 秒，一镜一个笑点、递进不重复：钩子（一眼看懂设定）→ 冲突（设定第一次生效）→ 互动（升级）→ 互动（换场景再来）→ 高潮（最过分的一次）→ 结尾 / 反转。
- 拟人旁白一镜一句，英文 3–6 词（`Meet the real boss.` `Send help.`），语气低沉略讽刺或反差的天真；字幕复述口播加一个 emoji。
- 低机位强化体型对比，表情特写是视觉锚点；场景固定一个；音效卡在动作点。
- 不要：购买障碍 / 卖点证明、超过 6 镜、每镜超过 4 秒、口播解释笑点。

## 7. 脚本卡怎么填

脚本卡是逐镜一致性的来源，先填它再写主体和逐镜。

- `pillar`：单元内容支柱原名之一；连续三条同支柱会被警告，下一集换权重最高且不是本次的支柱。
- `angleRationale`：一两句，为什么这个角度对**这个账号 / 这个品**成立（利用了什么特质、打破了什么障碍、为什么会被转发）。对标信息也写这里。
- `emotionalArc`：三段式「怀疑 → 专注 → 推荐」「惊讶 → 爆笑 → 反转」；逐镜 `emotion` 要落在这三段里。
- `visualStyle`：一句，光线 / 色调 / 机位感 / 画质取向。全局画质只写这里，不要每镜各抄一遍。
- `visualAnchor`：全片反复出现的画面锚点；至少一半的镜 `shotPrompt` 要出现它。
- `narrator`：`language` 与表一致；`toneInstruction` 一句（「轻快自然，UGC 口语」）；`voiceLabel` 指向 `@音频n`，没有音色资产就不填。
- `shootingNotes`：2–4 条（抓什么表情 / 角度、音效与转场、场景布置、CTA 位置）。
- `negativeDirectives`：全片禁项，编译进禁止行。
